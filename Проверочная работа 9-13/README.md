# Проверочная работа по физике. Уроки 9–13

Письменная проверочная работа для 7 класса: 7 заданий, все с развёрнутым
письменным ответом. Проверяются правила, определения и опыты из уроков
9–13 (§ 9, 12, 13, 14, 15) учебника Перышкина А. В. и др. (Просвещение, 2023).

## Состав работы

| № | Тема | Проверяется | Баллы |
|---|------|-------------|-------|
| 1 | § 9. Броуновское движение. Диффузия | определения броуновского движения, броуновской частицы и диффузии; причина броуновского движения | 3 |
| 2 | § 9. Притяжение и отталкивание молекул | удержание формы и объёма; расстояния проявления притяжения и отталкивания; осколки и слипание стёкол | 3 |
| 3 | § 12. Агрегатные состояния вещества | свойства трёх состояний и движение молекул; сжимаемость газа и жидкости | 3 |
| 4 | § 13. Молекулярное строение состояний | два фактора, определяющие свойства вещества; тепловое расширение; почему твёрдые тела не разрушаются | 3 |
| 5 | § 14. Механическое движение | определения движения, траектории и пути; относительность движения; путь и траектория, единицы в СИ | 3 |

**Оценивание:** 20–22 — «5», 16–19 — «4», 11–15 — «3», 0–10 — «2».
Время выполнения — 40 минут.

## Файлы

| Файл | Что это |
|------|---------|
| `Проверочная работа (9-13).pdf` | бланк для печати, 2 листа А4 (1 лист двусторонней печати на ученика) |
| `Проверочная работа (9-13).docx` | тот же бланк в редактируемом виде (Word) |
| `index.html` | бланк в браузере — открыть и нажать Ctrl+P (A4, поля 11/9 мм) |

| `Ключи (9-13).docx` | ключи в редактируемом виде |
| `Ключи.html` | ключи в браузере |

| `_topdf.py` | HTML → PDF через headless Chrome |

## Как пересобрать

```bash
python _build.py      # HTML + DOCX из описания заданий
python _topdf.py      # PDF из HTML
```

Чтобы изменить текст задания, ожидаемый ответ или критерии, правьте
`_build.py` (словарь `TASKS`) и запускайте обе команды заново.
Количество линий для письменного ответа задаётся словарём `ANS_LINES` —
например, `ANS_LINES[3] = 8` — это восемь линей под задание 3.

## Важно

Вёрстка рассчитана на **ровно 2 листа А4**. Если править текст вручную в Word,
не увеличивайте объём текста заданий: лишние строки вытолкнут «Итого/Оценка»
на третий лист. В HTML за это отвечает `ANS_LINES`, а блок задания помечен
классом `.taskbox` (`page-break-inside: avoid`) — вопросы не отрываются
от линий для ответа.
